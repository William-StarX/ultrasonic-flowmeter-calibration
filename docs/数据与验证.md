# 数据与验证

## 准备校准数据

`calibrate --data-dir <目录>` 从同一目录读取以下三份 CSV。文件名沿用随项目附带的试验数据格式。

| 文件 | 内容 |
| --- | --- |
| `attachment1_window_data.csv` | 一行一个试验窗口，包括唯一的 `window_id`、参考体积 `standard_volume_m3`、名义流量点、试验工况、基础积分估计和窗口级声道特征。 |
| `attachment6_window_raw_samples.csv` | 每个窗口的逐秒观测，包括窗口编号、时序、声道传播时间和温度等数据。每个校准窗口都需要匹配的逐秒观测。 |
| `attachment7_meter_geometry.csv` | 等效管径、弦位、声道映射和积分权重。 |

字段和单位参见 [试验数据字典](../data/calibration/attachment3_data_dictionary.csv)。使用自有数据时，三个表的窗口编号、声道映射和单位须一致。校准阶段需要参考装置测得的窗口体积。

## 评价体积估计

估计 CSV 包含 `window_id` 和 `model_volume_m3`。参考 CSV 包含 `window_id`、`date`、`flow_point`、`condition_note`、`disturbance_id` 和 `standard_volume_m3`。两个文件覆盖相同窗口，参考体积须为正数，体积单位均为 m³。使用 `no_disturbance_reference` 标记无扰流参考，使用 `disturbed_test` 标记扰流试验。

```powershell
python src/flowmeter evaluate --reference path/to/reference.csv --estimates path/to/estimates.csv --output-dir runs/check
```

| 输出 | 内容 |
| --- | --- |
| `evaluation_windows.csv` | 参考体积、估计体积和相对误差 |
| `evaluation_groups.csv` | 日期与流量点下至少三个重复窗口的误差均值、标准差、极差和通过状态 |
| `evaluation_summary.csv` | 总体 MAE、分组通过数、三项指标及阈值状态 |

评价沿用基准试验口径。线性度和扰流指标使用名义流量点 40 至 100 的记录。线性度、重复性与扰流指标的通过阈值分别为 0.036%、0.040%、0.115%。缺少足够的正常工况、重复窗口或可配对的扰流窗口时，相应指标可能为空。
